# Suggested Workflow

1. Read the tests first.
2. Identify which failures are caused by incorrect rule handling (depends on the EXERCISE.md file).
3. Fix the tests in small steps.
4. Add tests until coverage reaches 100%.
5. Identify bad code patterns in the implementation, and define a rule to fix each one.
6. Refactor only after each step is protected by tests.

## S.P.E.C. Prompting Principles

To get high-quality results, clearly define the following:

- **S (Status/Role):** Who is the agent? For example, a strict police investigator.
- **P (Precise Task):** What exactly is the agent supposed to do?
- **E (Examples/Tone):** How should the agent speak? For example, cynical, concise, or formal.
- **C (Constraints):** What must the agent avoid doing?
